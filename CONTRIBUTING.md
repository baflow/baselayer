# Contributing

Thanks for your interest in making this template better.

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-thing`)
3. Make your changes
4. Run `npm run build` to ensure the project builds cleanly
5. Commit your changes
6. Open a Pull Request

## Guidelines

- Keep dependencies minimal -- this is a template, not a framework.
- Follow the existing design token system in `DESIGN.md`.
- Use Tailwind utilities and Basecoat classes; avoid custom CSS in component `<style>` blocks.
- Prefer Svelte over Astro for reusable UI components (better Storybook support).
- Update `README.md` if your change affects setup or features.

## Questions?

Open a [GitHub Discussion](https://github.com/baflow/baselayer/discussions) or an Issue.
